Под наблюдением. **Механику упоминаний `/pivo` не трогать, пока O2 открыт** — любая правка смажет наблюдение (см. гейт у L2.1 в бэклоге). |

## Осознанно отложено — решения приняты, менять не нужно

| Что | Почему так |
|---|---|
| Fernet-ключ `/pivo` = `sha256(secret)` без KDF | Low. Переход на HKDF сломает расшифровку существующих подписок. Секреты по инструкции — длинные случайные. Решение от 2026-06-30: оставить. |
| Метрики/трейсинг, единый lock на SQLite-соединение, in-memory state (throttle, кулдауны, кэши) | Все три упираются в допущение «один инстанс». Актуальны, только если появится второй инстанс или воркер. |
| `/config` без `AdminOrOwner` | Read-only показ рантайм-настроек; секретов в `RuntimeState` нет. |
| `AUTO_CAPITALIZE_REPLIES=false` | Модель учится в нижнем регистре (`NORMALIZE_LOWER=true`); капитализация в чате читается неестественно. |

## Бэклог идей — не запланировано

- Verbatim у джампов: ответы с одним джампом несут ~0.3 дословности против ~0.02 без джампа (замер 2026-07-15) — точка входа, если цитирование корпуса снова станет проблемой.
- Лексическая отсебятина: слот-мутации фрагментов — **реализовано за выключенной ручкой, гард доведён, можно включать** (ветка `feat/slot-mutations`, 2026-07-17). Ручка `slot_mutation_probability` (дефолт 0): принятый кандидат выставляет рядом копию с одним заменённым контент-словом, копия конкурирует в скоринге. История качества: гард окончаний один давал ~40% морфологического мусора среди победителей (порог приёмки ≤10%) — системно, потому что verbatim-штраф вознаграждает любую мутацию; решение утверждено 2026-07-17 — добавлен `pymorphy3` (POS + падеж/число/род/время/лицо по лучшему разбору, ленивая инициализация, кэш тегов) + защита связок швов + отклонение местоимённых замен (NPRO/Apro, «которые»). Контрольный замер (2×4 сида × 200) и ручной разбор ~150 победителей: **мусор ~8–12%, на пороге**; остаток — не морфология, а валентность глаголов («она сильной имела») и разбитые идиомы («в том числе» → «в том деле») — гардом частей речи не ловится, дальше только семантика. Метрики стабильны: мутации выигрывают 8–13% ответов при p=0.15 и 13–22% при p=0.3, новизна/verbatim/якорность/пустые — без регресса. Рекомендация для старта: `p=0.15`. Включение — отдельным решением после окна O1.
- L2.1: обращение по имени к подписчикам `/pivo` (их имя уже хранится с opt-in). Privacy-ревью пройдено 2026-07-16: новых данных не собирается, меняется только показ. **Заблокировано до закрытия O2:** это правка механики упоминаний, а она под наблюдением. Реализация дешёвая — `build_pivo_mention` уже умеет именную ссылку `tg://user?id=` как фолбэк для подписчиков без ника, нужен только выбор между формами. Но осторожно с обоснованием: именная ссылка — не «страховка по O2» (протухший ник там ни при чём), а замена надёжного канала уведомлений `@ник` на более капризный; при живом `@нике` это скорее риск, чем польза.
- Интонационный профиль чата: выучиваемая средняя длина и пунктуация.
