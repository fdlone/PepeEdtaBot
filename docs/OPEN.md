## Осознанно отложено — решения приняты, менять не нужно

| Что | Почему так |
|---|---|
| Fernet-ключ `/pivo` = `sha256(secret)` без KDF | Low. Переход на HKDF сломает расшифровку существующих подписок. Секреты по инструкции — длинные случайные. Решение от 2026-06-30: оставить. |
| Метрики/трейсинг, единый lock на SQLite-соединение, in-memory state (throttle, кулдауны, кэши) | Все три упираются в допущение «один инстанс». Актуальны, только если появится второй инстанс или воркер. |
| `/config` без `AdminOrOwner` | Read-only показ рантайм-настроек; секретов в `RuntimeState` нет. |
| `AUTO_CAPITALIZE_REPLIES=false` | Модель учится в нижнем регистре (`NORMALIZE_LOWER=true`); капитализация в чате читается неестественно. |

## Бэклог идей — не запланировано

- CI на push запускается только для `main` (плюс на каждый pull_request). Поломка в ветке без PR не видна, а в `main` — уже постфактум: так красный bandit-гейт из #80 прожил в `main` полдня. Снять фильтр `branches: [main]` с push-триггера, если частота прогонов не смущает.
- Чистка корпуса при обучении: мусор вида «5.» из нумерованных списков попадает в модель.
- Verbatim у джампов: ответы с одним джампом несут ~0.3 дословности против ~0.02 без джампа (замер 2026-07-15) — точка входа, если цитирование корпуса снова станет проблемой.
- Лексическая отсебятина: слот-мутации фрагментов (замена контент-слова корпусного сегмента на частотное слово чата). После O4-фикса ценность пересмотрена: честная новизна уже 0.57–0.62, треть-пересказов больше нет — мутации теперь про «добить хвост», а не спасать положение. Метрика готова (`novel_ngram_share`). Риск несогласованности русской морфологии, нужен гард.
- Сегментация якоря (идея 2026-07-15, обсуждена, не реализована): позиция контекстного якоря варьируется (начало/середина/конец ответа) — «прыжок наоборот», глобальный старт + сплайс якоря позже. Делит jump-бюджет с `context_jump_boost`. Структурная живость без лексической новизны.
- L2.1: обращение по имени к подписчикам `/pivo` (их имя уже хранится с opt-in) — требует отдельного privacy-ревью.
- `/pivo`: рекурсивные шаблоны (слоты внутри слотов), сезонные пулы.
- Эскалационные цепочки: бот «заводится» при серии упоминаний.
- Интонационный профиль чата: выучиваемая средняя длина и пунктуация.
