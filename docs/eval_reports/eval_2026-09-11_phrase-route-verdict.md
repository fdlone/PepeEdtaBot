# Гейт маршрутов M3R-220 — второй прогон: фразовый маршрут M3R-210 — вердикт 2026-09-11

Change `phrase-route`. Маршрут реализован в этой же заявке (ручки
`phrase_slot_ratio` / `phrase_min_count`, дефолты 0 / 3, `generation_hash`
не сдвинут на обоих снимках — `hash-log.md` заявки). Гейт — существующий блок
`route_gate` (зарегистрирован 2026-09-02, один на все маршруты); новых порогов
не регистрировалось, ожидания записаны до прогона в design D6 и в шапке
`tools/eval/matrix_phrase_route.yaml`. Прод-копия **10.09**
(`markov-20260910-123542`, индекс пересобран суточным пассом), набор
`bababb4b7693`, 500 генераций × 3 сида на арм, оба режима. Отчёты:
`eval_2026-09-11_phrase-route_{ctx,noctx}.md`, JSON
`phrase-route-{ctx,noctx}.json`. С отчётами по копии 01.09 абсолютные
значения C0 несопоставимы (другой снапшот); сопоставимы только дельты к C0.

Маршрут под гейтом выведен из данных: `phrase` — единственный маршрут,
присутствующий в пулах армов `C11p*` и отсутствующий в C0. Армы несут
`verbatim_recognized_unit: true` (M3R-120 — обязательный спутник маршрута по
роадмапу); контроль `C11v` несёт только его и по построению читается
`insufficient data` (нового маршрута в пулах нет) — он здесь для атрибуции.

## Что это значит

**Четвёртый независимый замер одного факта** (M3R-011, M3R-100, M3R-220 по
assoc, теперь M3R-220 по phrase): маршрут создаёт пространство в пуле
(ECB +0.07…+0.16\*) и не создаёт его в окне. Фраза либо не попадает в окно,
либо попадает и **выигрывает** (win|present 35–40% в обоих режимах, у
вытесняемого обхода win падает с 0.74 до 0.55–0.62 в ctx) — но одна траектория
в окне заменяется другой, а не дополняется.

При этом фразовый маршрут — **первый, у которого сигнал тематичности без
копий положителен и велик в обоих режимах**: в ctx +0.057\* (0.250 → 0.294)
при copy −3.1 п.п.\*, в noctx +0.062\* (0.034 → 0.096, почти втрое).
Ассоциативный маршрут на том же гейте давал в ctx affinity флэт при copy
−2.3…−3.0 п.п.\*, в noctx +0.007…+0.012\*. Победители фразового маршрута
несут affinity 0.35 / 0.25 (ctx / noctx) против 0.29 / 0.03 у обхода при
copy 0.01 / 0.00 против 0.28 / 0.01 — фраза с якорем входа тематична и не
копирует вход, ровно то, что гипотеза «различное и тематичное одновременно»
и обещала. Это не меняет вердикт гейта: планка — окно, а не тематичность.

**Порог поддержки как плечо.** Coverage падает с порогом (76 → 67 → 56%),
но остаётся впятеро выше пола на самом строгом плече — ожидание «cnt≥5
ниже 10%» не сбылось: верхняя оценка по точкам прицепа из переписи 23.08
(1.1–8.4% состояний цепи) была оценкой другого механизма (сплайсинг в
прогулку), а якорный отбор дотягивается до входа, если хоть одна фраза чата
содержит его контентный токен. Качество с порогом двигается в обе стороны:
affinity выше на cnt≥2, escape окна и meme rate выше на cnt≥5. Ни одно
плечо не выделяется как решающее — must-improve не берёт ни одно.

**Контроль `C11v`** (исключение M3R-120 без маршрута): copy, affinity, ECB,
meme rate — флэт в обоих режимах; escape окна +0.037\* (ctx) / +0.098\*
(noctx); длина −0.13\* / −0.10\*. То есть исключение само по себе слегка
расширяет окно и укорачивает ответ, а все сдвиги тематичности и копий у
армов маршрута принадлежат маршруту, не исключению.

## Что не сделано и почему

- Соло-раунд связности не готовился: вердикт fail по must-improve не зависит
  от него.
- Гейт **не смягчается задним числом**: планка −0.05 записана 2026-09-02.
- Дефолты `phrase_slot_ratio = 0` / `phrase_min_count = 3` остаются;
  промоушен возможен только отдельным изменением после `pass`.

## Следствие для роадмапа (решение владельца)

Следующий арм, вытекающий из четырёх замеров, тот же, что предложен после
assoc: **маршрут вместе с ручкой отбора** под тем же `route_gate`. Новое в
этом вердикте — какой маршрут ставить в пару: фразовый несёт в окно
тематичного кандидата без копии (affinity победителей 0.35 против 0.29 у
обхода в ctx), поэтому цена тематичности у `selection_diversity_bonus` 0.2
(M3R-100: −0.010\* на одном обходе, O19) рядом с ним может оказаться не
ценой, а прибавкой. Кандидат на арм: `phrase_slot_ratio` 0.4 +
`phrase_min_count` 2 + `selection_diversity_bonus` 0.2 (+
`verbatim_recognized_unit`). Это отдельная заявка; здесь ничего из неё не
пре-регистрировано.
