# Промоушен hot-маршрута и пары «фраза + бонус» — приёмочный замер пакета, 2026-09-11

Change `promote-hot-and-phrase-routes`. Решение владельца 2026-09-11: включить
всё, пару — в обоих режимах. Семь дефолтов реестра: `hot_ngram_slot_ratio`
0 → 0.4, `hot_ngram_min_count` 3 → 2, `hot_ngram_recency_share` 0.5 → 0.25,
`phrase_slot_ratio` 0 → 0.4, `phrase_min_count` 3 → 2,
`selection_diversity_bonus` 0 → 0.2 (noctx-ручка 0.2 с O19),
`verbatim_recognized_unit` false → true. Основания — гейты:
`l1_hot_channel` (`eval_2026-09-02_l1-route-verdict.md`, раунд
`eval_2026-09-11_l1-route-v5-round-verdict.md`) и `route_gate` в ctx
(`eval_2026-09-11_route-selection-verdict.md`, раунд
`eval_2026-09-11_route-selection-round-verdict.md`).

**Зачем отдельный замер.** Hot-маршрут и фразовый маршрут в noctx вместе не
измерялись: hot занимает 2 слота, фраза 2, обходу остаётся 1 из 5. Это не
новый гейт — страховочные условия уже зарегистрированных блоков, снятые на
**совместной** конфигурации: ECB пула ≥ 4.0, copy и repetition не растут
значимо, affinity без копий не падает значимо, p95 ≤ 150. Ожидания записаны до
прогона в шапке `tools/eval/matrix_promotion_check.yaml`.

Матрица: `C0` — прежние дефолты, заданные явными оверрайдами; `CP` — новые
дефолты реестра. Прод-копия 10.09, набор `bababb4b7693`, 500 × 3 сида, оба
режима. Отчёты `eval_2026-09-11_promotion-check_{ctx,noctx}.md`, JSON
`promotion-check-{ctx,noctx}.json`.

до шума; в noctx ECB совместного пула **выше**, а не ниже обеих половин
(hot-кандидаты не дублируют обход, фразы добавляют траектории), обходу
одного слота хватает.
