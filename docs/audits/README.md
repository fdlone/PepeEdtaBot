# Audit history

Единая история аудитов и ревью проекта. Конвенция: каждый аудит — датированный
файл `YYYY-MM-DD-<slug>.md` или директория `YYYY-MM-DD-<slug>/` в этой папке;
итоги сессии дописываются в текущий файл, статусы находок обновляются здесь.

Активные рабочие документы фич (например, `docs/DIALOGUE_GENERATION_AUDIT.md`)
живут в `docs/` рядом с ARCHITECTURE.md и сюда переезжают только после
завершения соответствующего цикла работ.

## Открытые / отложенные решения

- **SIM-8** (Low, 2026-07-12): `strip_leading_bot_vocative` не срезает
  обращение «пепе текст» без разделителя — корпус учит имя бота, и бот
  повторяет его в ответах. Ждёт решения о фиксе.
- **SIM-9** (Info, 2026-07-12): hidden-context ветка
  (`reply_context_emit_start=false`) мертва при дефолте; удаление флага не
  меняет поведение. Ждёт решения пользователя.
- **S3** (Low, deferred 2026-06-30): Fernet-ключ = sha256(secret) без KDF —
  смена схемы сломает расшифровку существующих /pivo-подписок; секреты по
  инструкции случайные 32+ символов.
- **Масштабирование** (не актуально для single-instance): L3 метрики,
  P1 единый lock на SQLite-соединение, A4 in-memory state при нескольких
  инстансах.
