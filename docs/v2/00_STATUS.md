## С чего начинать следующую сессию

1. `/opsx:propose markov2r-phase3-temporal-layer-core` (M2R-200/210, ТЗ §7–8) →
   approval владельца → apply. Миграция добавляет `first_seen/last_seen/
   s_value/s_updated_at`; исторические `first_seen` = дата миграции (аудит §8),
   поэтому temporal-метрики доступны только после окна накопления.
2. **Решение по коду Phase 2** (за владельцем): ручки выключены и ничего сейчас
   не дают. Оставить (Phase 3 меняет само распределение весов, из которого
   считается энтропия — сублинейное сжатие long-слоя разглаживает те самые
   пиковые пулы, что дали 78.8% безальтернативных шагов; перезамер тогда почти
   бесплатен) либо удалить как мёртвый вес. Перезамер — только с **новым**
   предрегистрированным гейтом, старый использован.
3. Фоновая гигиена (вне 2.0R, по желанию): подъём yanked `aiogram 3.29.0`
   отдельным change; `actions/checkout@v4` предупреждает о Node 20.
