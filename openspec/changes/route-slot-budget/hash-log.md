## Ожидание — записано до правок

Сдвига **нет ни на одном снимке**. Основание конкретное, а не «правка
маленькая»: `tools/generation_hash.py` строит состояние из дефолтов реестра,
где `markov_seeded_candidate_ratio = 0`; при нулевой ручке маршрутный блок не
исполняется (существующий гейт `if ratio > 0.0`), поэтому цикл попыток
стартует с пустым пулом ровно как сейчас и порядок потребления RNG не
меняется (design D4).

Расхождение с ожиданием означает, что правка задела нейтральный путь: работа
останавливается и разбирается, ожидание не переписывается задним числом
(§2 `CLAUDE.md`).

## Размер пула на арме с включённым маршрутом (задача 4.2)

Прогон `run_matrix` на прод-копии, армы C0/C4, 3 сида × 60 генераций,
`pool_size` из записей:

- **до правок:** C0 — 5.000 (макс 5, только 5); C4 — **6.400** (макс **7**,
  распределение {5, 6, 7})
- **после правок:** C0 — 5.000 (макс 5); C4 — **5.000** (макс **5**)

При этом seeded остаётся в пуле: `seeded_present_rate` по сидам 0.833 / 0.783 /
0.783 (R2 давал 0.82 на прежней схеме), `win|present` 0.380 / 0.362 / 0.255.
То есть маршрут не вытеснен из пула, а переведён в конкуренцию за места —
ровно то, ради чего делалась ветвь 2.
