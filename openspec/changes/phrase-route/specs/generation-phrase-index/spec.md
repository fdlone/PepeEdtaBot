## MODIFIED Requirements

### Requirement: Индекс не меняет поведение бота

Появление индекса MUST NOT изменить ни один ответ бота, ни одно решение
генерации и ни один разыгранный жребий, пока фразовый маршрут выключен: с
2026-09-11 у индекса есть единственный читатель на пути ответа — фразовый
маршрут (M3R-210), и он читает индекс только при ручке `phrase_slot_ratio`
выше нуля. При её значении по умолчанию (0) индекс на пути ответа не читается.

Ведение индекса MUST NOT добавлять работы на путь обучения: единственная запись
после заполнения — фоновая пересборка. Чтение на пути ответа при включённом
маршруте SHALL быть не более одного обращения к индексу на генерацию.

#### Scenario: Ответы не изменились

- **WHEN** система отвечает при наличии индекса и ручке маршрута по умолчанию (0)
- **THEN** ответ тот же, что был бы без него, и индекс не читается

#### Scenario: Индекс читается только маршрутом

- **WHEN** ручка маршрута выше нуля
- **THEN** индекс читается не более одного раза за генерацию, и только фразовым маршрутом

#### Scenario: Путь обучения не подорожал

- **WHEN** сообщение выучивается
- **THEN** индекс при этом не пишется
