## ADDED Requirements

### Requirement: Порог, определяющий объём фоновой работы, ограничен снизу

Настройка, которая задаёт минимальную поддержку для попадания в фоновый анализ,
SHALL иметь нижнюю границу строго выше значения, при котором анализ теряет
смысл. Одно-единственное совместное наблюдение не является свидетельством
устойчивой пары, а снятие порога переводит фоновую работу с осмысленного
подмножества на весь корпус.

#### Scenario: Попытка снять порог

- **WHEN** порогу поддержки задаётся значение, при котором в анализ попадает всё подряд
- **THEN** значение отвергается с указанием допустимого диапазона

#### Scenario: Значение внутри диапазона

- **WHEN** порог задаётся в пределах допустимого
- **THEN** значение принимается, и следующий фоновый проход считает по новому порогу
