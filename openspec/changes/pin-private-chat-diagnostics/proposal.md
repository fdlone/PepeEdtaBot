# Pin private chat diagnostics

## Why

README утверждает: «Команды предназначены для групповых чатов. Личный чат с
ботом не является поддерживаемым рабочим сценарием». Код с этим расходится:
`GROUP_ONLY` стоит у `/stats` и всех admin/pivo-команд, но не у `/ping`,
`/help` и `/config` — в личке они отвечают. Молчаливое расхождение уже один
раз стоило ошибочной посылки при ревью 2026-08-26 («все команды GROUP_ONLY»).
Открыт как O13 в `docs/OPEN.md`.

Решение владельца (2026-09-01): личка **нужна** — это канал диагностики и
отчётов, потому что у владельца нет прямого доступа к докеру, на котором
развёрнут бот (логи недоступны; отчёты `/pivo` уже приходят в личку — PR #111).
Диагностике достаточно `/ping` и `/help`; `/config` показывает действующие
настройки чата, а в личке чата нет — команда уходит под `GROUP_ONLY`.
Остальное закрепляем: правим README и пиннируем состав исключений тестом,
чтобы следующий хендлер попадал в списки осознанно.

## What Changes

- `/config` получает фильтр `GROUP_ONLY` — в личке перестаёт отвечать
  (единственное изменение поведения; настройки — свойство конкретного чата,
  в личке им взяться неоткуда).
- README: абзац о командах переформулируется — рабочий сценарий групповой,
  личный чат поддерживается как канал диагностики и отчётов владельцу
  (`/ping`, `/help`; отчёты `/pivo` в личку); таблица команд получает
  признак доступности в личке.
- Новый тест закрепляет точный состав исключений: множество команд без
  `GROUP_ONLY` равно `{ping, help}` — тест падает и при потере фильтра
  существующей командой, и при появлении новой команды без явного решения
  о личке.

## Capabilities

### New Capabilities

- `private-chat-diagnostics`: какие команды отвечают в личном чате и почему —
  диагностический канал владельца при недоступности логов; всё остальное
  только в группах.

### Modified Capabilities

_нет_

## Impact

- `app/handlers/admin.py` (одна строка — фильтр у `/config`), `README.md`
  (раздел «Команды»), новый тест в `tests/` (состав исключений `GROUP_ONLY`),
  `docs/OPEN.md` (O13 закрывается) + `docs/CLOSED.md`.
- `generation_hash` не задет по построению: ни один файл пути генерации не
  трогается (хендлеры в хеш не входят).
