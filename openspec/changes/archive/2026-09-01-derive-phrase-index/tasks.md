- [x] 4.2 Тест идемпотентности: два прогона подряд без новых сообщений дают

- [x] 4.3 Тест: пересборка **заменяет**, а не дополняет — фраза, исчезнувшая из

- [x] 4.4 Тест согласованности с цепью: на подготовленных данных содержимое
      индекса совпадает с прямым отбором фраз по `transitions` тем же фильтром
