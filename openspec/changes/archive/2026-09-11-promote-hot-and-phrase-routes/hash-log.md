## Ожидание — записано до правок

Сдвиг **есть на обоих снимках**, и это цель заявки. Причины, все — дефолты
реестра (код генерации не меняется):

1. `hot_ngram_slot_ratio` 0 → 0.4 — только ответы без контекста; гард
   генерирует с контекстом, поэтому на хеш **не** влияет;
2. `hot_ngram_min_count` 3 → 2, `hot_ngram_recency_share` 0.5 → 0.25 —
   пороги горячести; через `protected_tokens` слот-мутаций влияют и на ctx;
3. `phrase_slot_ratio` 0 → 0.4, `phrase_min_count` 3 → 2 — два слота пула
   из фраз в обоих режимах;
4. `selection_diversity_bonus` 0 → 0.2 — отбор в ctx;
5. `verbatim_recognized_unit` false → true — штраф за цитату.

Перезаморозка одна, после всех правок (design D1).
