## Context

Мотивация — `proposal.md`. Сборка раунда сейчас: `_round_entries` (выборка
по рукам, склейка одинаковых текстов, декои, повторы поверх всего списка) →
`_shuffle_spreading_repeats` (повторы не рядом) → список и ключ. Валидность
`score_round` — по всему раунду из блока `phase9_interp`.

## Goals / Non-Goals

**Goals:** контроль само-согласия помещается в один присест; инструкция
исключает трактовку «повтор = 1»; форма генерируется инструментом.

**Non-Goals:** пороги валидности, шкала, декои — без изменений; межсессионный
дрейф не измеряется и не штрафуется; второй оценщик — вне заявки.

## Decisions

### D1. Сессия — единица сборки контролей, валидность — по раунду

Различные записи (реальные + декои) режутся на `ceil(n / session_size)`
блоков: декои раздаются по кругу (в каждом блоке ≥ 1), реальные —
по-очереди в самый короткий блок. **Внутри** блока добираются повторы
(`ceil(len × repeat_share)`, вверх) и применяется прежнее разведение.
Валидность (0.80 / 0.80 / 0.20 / 30) читается по всему раунду, как и была
зарегистрирована; по сессиям агрегат печатает само-согласие и декои как
диагностику — чтобы было видно, какой присест поплыл. Альтернатива
«валидность по каждой сессии» отвергнута: это новый порог, а пороги задним
числом не заводятся.

### D2. Дефолт 25 различных позиций

С повторами ≈ 30 позиций на присест. Раунды 11.09 показали, что 75 без
перерыва не держатся; `pool-c8s40` у двух оценщиков — по 66 на человека —
держались. 25 — параметр подготовки (`--session-size`), не порог.

### D3. Форма — часть инструмента

Шаблон `tools/rating_form_template.html` — тот, которым оценивались раунды
v5 и `route-selection`, без единого текста чата (плейсхолдеры `__ITEMS__`,
`__LABEL__`) плюс инструкция. `prepare` пишет `form_s<N>.html` на сессию;
метка формы включает номер сессии, чтобы прогресс сессий не смешивался в
хранилище браузера; позиции глобальные, поэтому ответы сессий сливаются в
один агрегат (`score --answers a.txt --answers b.txt`).

### D4. Совместимость ключей

Старые ключи без `session` читаются как одна сессия; старые списки без
заголовков сессий разбираются как прежде.

## Risks / Trade-offs

- [Доля повторов по сессии округляется вверх → общая доля чуть выше 20%] →
  это плюс для контроля и ноль для валидности.
- [Маленький раунд (< 25 различных)] → одна сессия, поведение прежнее.
