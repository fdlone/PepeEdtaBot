## ADDED Requirements

### Requirement: Удаление по сроку хранения фактически запускается

Механизм, запускающий удаление устаревших записей, SHALL срабатывать независимо от того, через какое представление состояния идёт активность чата.

Предел по числу записей SHALL оставаться страховкой, а не единственным работающим ограничением: срок хранения объявлен как самостоятельное требование и должен соблюдаться до того, как состояние упрётся в предел по объёму.

#### Scenario: Активность идёт через представление с переопределениями

- **WHEN** активность чата обрабатывается через представление состояния, созданное из-за переопределений настроек
- **THEN** служебные счётчики обслуживания продвигаются в общем состоянии
- **AND** удаление устаревших записей запускается так же, как для чата без переопределений

#### Scenario: Устаревшая запись при незаполненном пределе

- **WHEN** запись устарела по сроку, а общее число записей далеко от предела
- **THEN** запись всё равно удаляется
