# Design — extension-seam-accounting

## Context

Мотивация — proposal. Кандидаты уже несут `route` (`_ScoredCandidate.route`,
M3R-103), победитель выбирается в `generate_with_result`
(`select_scored_candidate` → `selected.route`), но
`ResponseGenerationResult` отдаёт только `text` и `candidates_scored`.
Свип-харнесс `tools/eval_prod.py` перехватывает `gen_trace_log.log_selection`
(kwargs несут `selected`) и считает `connective_reply_rate` текст-сканом
`contains_splice_connective`, который молчаливую связку исключает намеренно.

## Decisions

- **D1 — `winner_route: str | None` на результате, не новый канал.**
  Значение уже вычислено для телеметрии (`note_routes(winner=...)`);
  результат — естественное пер-ответное место. `None` при пустом ответе.
- **D2 — честный числитель = текст-скан ∨ шов по построению.** Шов по
  построению: маршрут победителя `extension` **или** `jump_count > 0` у его
  проходки (у харнесса оба сигнала уже в руках: `selected` из хука и
  `attempt_jump_counts`). Текст-скан остаётся в числителе: он ловит словесные
  связки у ответов, чью проходку харнесс не видел (страховка от рассинхрона
  хуков).
- **D3 — отдельная метрика `extension_seam_rate` рядом.** Смена числителя
  без видимой дельты была бы молчаливой правкой исторического ряда; доля
  дописок отдельным числом делает вклад поправки читаемым в каждом отчёте.
- **D4 — разрыв сопоставимости обозначается в выводе харнесса** (поле/строка
  рядом с метрикой), а не только в доке — прецедент `distinct_basis_tokens`
  из методики 2026-07-21. Перекалибровка порога «~0.8» — отдельным решением
  после первого честного замера (за пределами этого изменения).

## Risks / Trade-offs

- [Числитель вырастет на всех будущих свипах] → это и есть цель; парные
  сравнения внутри одного прогона остаются валидными, межэпохные — нет,
  что и обозначено (D4).
- [`winner_route` расширяет публичный результат] → одно опциональное поле с
  дефолтом `None`; существующие потребители (`reply_pipeline`) его не читают
  и не обязаны.

## Migration Plan

Обычный мерж; изменение живого поведения — ноль (телеметрия и оффлайн-харнесс).
