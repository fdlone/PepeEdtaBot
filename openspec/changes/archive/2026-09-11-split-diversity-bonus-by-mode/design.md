## Context

Мотивация — `proposal.md`. Бонус применяется в одной точке
(`generate_with_result`, перед `select_scored_candidate`) функцией
`apply_diversity_bonus(candidates, bonus)`; при `bonus <= 0` она возвращает
список как есть. Режим генерации известен там же: `request.context_tokens`
пуст у ответов без контекста (харнесс `run.py` подаёт `[]` в `noctx`, прод —
самоинициированные ответы).

## Goals / Non-Goals

**Goals:** бонус 0.2 там, где он прошёл гейт (noctx); ctx байт-в-байт.

**Non-Goals:** не трогать `apply_diversity_bonus`, окно, температуру;
не заводить допуск на тематичность для ctx (вариант 1 O19 отклонён
владельцем); не регистрировать новых порогов.

## Decisions

### D1. Вторая ручка, а не режимный множитель

`selection_diversity_bonus_noctx` — отдельная `FieldSpec` того же домена
(0..1). Альтернатива «одна ручка + булев флаг только-noctx» отклонена: два
числа читаются и свипаются независимо (`knob_census` увидит обе), а флаг
прячет одно значение за другим.

### D2. Выбор в точке применения

```
bonus = (
    state.selection_diversity_bonus
    if request.context_tokens
    else state.selection_diversity_bonus_noctx
)
```

Ровно одна строка условия; трасса и телеметрия видят поднятые скоры как и
прежде. Критерий «есть контекст» — тот же, что у `note_context_mode` и у
харнесса (`context_tokens` непустой), поэтому прод-доля 89/11 применима.

### D3. Хеш и сопоставимость

`tools/generation_hash.py` генерирует только с контекстом → ctx-ручка 0 →
хеш не двигается на обоих снимках (ожидание в `hash-log.md` до правок).
C0 харнесса в noctx с этого момента включает бонус 0.2: абсолютные noctx-числа
новых отчётов несопоставимы со старыми; дельты внутри отчёта — сопоставимы.
Это записывается в README харнесса и в CLOSED.

## Risks / Trade-offs

- [Бонус выше запаса окна сужает окно (d40 в noctx: coverage +2.0)] → дефолт
  0.2 ниже запаса 0.3; кросс-полевой инвариант не заводится: домен 0..1
  сохраняет свободу свипа, а вердикт 02.09 уже записал правило «бонус не
  выше запаса» словами.
- [Связность в noctx не измерена] → гейт её там не требует (решение при
  регистрации `route_gate`/`selection_window`); O18 покажет noctx-раунд для
  hot-маршрута отдельно.

## Migration Plan

Дефолт реестра; редеплой без миграций. Откат —
`/set selection_diversity_bonus_noctx 0` без рестарта.
