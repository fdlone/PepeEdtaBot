# Chat timezone for temporal branches

## Why

«Ночные» и «пятничные» ветки считаются по часам контейнера, а TZ нигде не
задан: `_temporal_bottoms` (`app/services/pivo_message_builder.py:185`) и
`is_late_night` (`app/presentation/fallback_phrases.py:106`) получают naive
`datetime.now()` из двух точек вызова (`app/handlers/pivo.py:241`,
`app/services/reply_pipeline.py:670`), базовый образ — UTC. Для чата в MSK
ночные строки играют с 03:00 до 09:00 по местному, пятничные смещены на три
часа. Снаружи это выглядит как случайный шаблон и само не заметится; README
обещает «временны́е вариации (ночь/пятница/понедельник)» без оговорок.

Открыт как O12 в `docs/OPEN.md`; там же выбрана развилка: явная настройка,
а не `TZ` контейнера — поведение не должно зависеть от окружения, и локальный
запуск обязан вести себя как прод.

## What Changes

- Новая env-настройка `CHAT_TIMEZONE` (IANA-имя, дефолт `UTC`): читается в
  `Settings`, валидируется на старте через `zoneinfo.ZoneInfo` — неизвестный
  ключ роняет запуск с внятной ошибкой, а не молча играет не те шаблоны.
  Дефолт `UTC` сохраняет текущее поведение байт-в-байт до явного включения.
- Обе точки вызова переходят на `datetime.now(<настроенная зона>)`; зона
  доводится до них полем `RuntimeState` по образцу `runtime_state_ttl_sec`
  (env-only, не runtime-mutable: часовой пояс — свойство деплоя, не ручка).
- `.env.example` документирует настройку с примером `Europe/Moscow`.
- Служебные сутки (`datetime.now(UTC)` в капах и квотах) **не трогаются** —
  различие «служебное время UTC / человеческое время чата» становится
  зафиксированным решением, а не умолчанием.
- Новая зависимость `tzdata` (обоснование по правилу «новая — только с
  обоснованием»): чистые данные IANA без кода, официальный fallback stdlib
  для `zoneinfo`; на Windows-машине разработки базы зон нет вовсе (проверено:
  `ZoneInfoNotFoundError`), а для `python:3.14-slim` наличие системной tzdata
  не гарантировано контрактом образа. На системах с базой пакет просто не
  используется (TZPATH первичен).

## Capabilities

### New Capabilities

- `chat-local-time`: временны́е ветки текста (ночь/пятница/понедельник/сезон в
  `/pivo`, ночной пул фолбэков) вычисляются в явно настроенном часовом поясе
  чата; служебные сутки остаются на UTC.

### Modified Capabilities

_нет_

## Impact

- Код: `app/config/settings.py` (чтение и валидация), `app/config/runtime_state.py`
  (поле + `build_runtime_state`), `app/handlers/pivo.py:241`,
  `app/services/reply_pipeline.py:670` (обе точки — только аргумент `now=`).
- Зависимости: `+tzdata` в `requirements.txt` и `requirements.lock`.
- Доки: `.env.example`; `docs/OPEN.md` (O12 закрывается); `docs/GENERATION_MAP.md`
  — правка задевает `reply_pipeline.py`, карта актуализируется по её §5.
- `generation_hash`: сдвига **нет** ни на прод-копии, ни на синтетике — правка
  не касается пути генерации (момент времени не питает ни RNG, ни цепь);
  ожидание фиксируется до правок и сверяется после, по образцу
  `derive-phrase-index`.
